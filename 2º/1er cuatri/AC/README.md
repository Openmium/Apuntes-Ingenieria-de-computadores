# 🧠 Arquitectura de Computadores

## 📌 Consejo sobre esta asignatura

**Arquitectura de Computadores** es distinta de **Estructura de Computadores**, pero **no es mucho más complicada**. Cambia un poco el enfoque: aquí se entra más en cómo se ejecutan las instrucciones y cómo se organiza el procesador internamente.

Te recomiendo **mirar estos apuntes**, ya que considero que están bastante bien hechos.  
Eso sí, **comprueba siempre que incluyen todo lo que se pide en la asignatura**, porque no sé si estarán actualizados en el momento en que leas esto.

### 🧾 Apuntes y problemas

- Al final de los apuntes tienes una **hoja con las instrucciones MIPS64**, muy útil para estudiar y resolver ejercicios.
- También hay un **cuadrante/plantilla** para resolver problemas de **pipeline**, que viene muy bien para no liarte con las etapas.

En general, si llevas la asignatura al día y practicas los problemas típicos, **no debería darte muchos quebraderos de cabeza**.
